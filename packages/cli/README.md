# argos-harness

A global-first CLI harness for setting up and managing Claude Code across your projects.

## Installation

```bash
npm install -g argos-harness
```

## Commands

- **init** — Install the Argos engine into the global Claude Code home.
- **adopt** — Detect a repo's stack and write its argos.config.json.
- **doctor** — Report drift between the engine, the repo config, and its ficha.
- **workspace** — Manage workspace registration, link repositories, and manage agents.
- **remove** — Uninstall the Argos engine from the global Claude Code home.
